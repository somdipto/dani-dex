These 16 transparent PNG poses are baked from the Dani-Dex Three.js robot rig at base 8078d11. The default role uses its white body and colored lower shell/soles, without role accessories. The baker explicitly colors that lower shell because the desktop default role ignores its color argument.

Generation requires Three.js 0.180.0, esbuild, playwright-core and Chrome. Bundle render.ts to render.js with esbuild, then run generate.cjs. These are static activity poses, not continuous 3D animation. Android-native visual validation is still required.
