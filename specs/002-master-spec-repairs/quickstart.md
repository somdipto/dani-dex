# Review and recovery

Use the pinned Bun version from package.json. Install with bun install --frozen-lockfile.
Use bun run dev --isolated and only this worktree's dev:automation instance.
In onboarding, review and keep context, then complete setup. Pending failures are reported.
Open Chief's Memories on the original local account to retry. Remote panels do not offer local batches.
For an older batch, use Review older imports, inspect the content/destination and explicitly keep it.
Stop this worktree with bun run dev:stop. No installer, tag or update release is published by this patch.
