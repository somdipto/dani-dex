# dani-dex-onboard

One command to install [Dani-Dex](https://github.com/somdipto/dani-dex) and open onboarding.
The same command works on Windows, macOS and Linux:

```bash
npx dani-dex-onboard
```

It detects your platform, downloads the newest release from GitHub, installs it and
opens the app, where onboarding starts. Requires Node.js (npm/npx ship with it).

Options: `--no-launch`, `--install-dir <path>`, `--dry-run`, `--help`.
